Guía de Integración con MongoDB Compass

Cómo conectarse e inspeccionar visualmente la base de datos yape_fraude desde la aplicación de escritorio MongoDB Compass en tu laptop.

1. Conexión en MongoDB Compass
  1. Abre MongoDB Compass en tu computadora.
  2. En la barra de conexión superior, pega la cadena de conexión estándar:
  3. Haz clic en "Connect".
  4. Verás la base de datos yape_fraude creada automáticamente con las siguientes 5 colecciones:
  • usuarios Índices multikey
  • transacciones Inmutables
  • aristas_flujo Proyección ($merge)
  • alertas_fraude Índice ESR
  • reportes_estafa Denuncias
2. Pipelines de Agregación para Compass

Ve a la pestaña "Aggregations" de cada colección en Compass y pega estos pipelines para reproducir las consultas del informe:

[
  { "$unwind": "$dispositivos" },
  { "$group": {
      "_id": "$dispositivos.device_id",
      "total_cuentas": { "$sum": 1 },
      "cuentas": { "$push": "$nombre_completo" }
  }},
  { "$match": { "total_cuentas": { "$gte": 3 } } },
  { "$sort": { "total_cuentas": -1 } }
]
[
  { "$graphLookup": {
      "from": "aristas_flujo",
      "startWith": "$id_receptor",
      "connectFromField": "id_receptor",
      "connectToField": "id_emisor",
      "as": "cadena",
      "maxDepth": 4,
      "depthField": "nivel_salto"
  }},
  { "$match": {
      "$expr": { "$in": ["$id_emisor", "$cadena.id_receptor"] }
  }}
]
